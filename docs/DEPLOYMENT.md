## Binary asset limitation

The current connected GitHub write interface can create UTF-8 files but does not expose a binary upload operation. SVG assets are therefore deployed directly; PNG/JPG assets are retained as local deliverables until a binary-capable upload route is available.

## Verification rule

A stage is complete only when the resulting GitHub resource can be fetched and inspected after the write.
